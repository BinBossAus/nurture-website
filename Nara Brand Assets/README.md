# Nara brand assets

The same visual system as Nurture, applied to "Nara" — built for cross-promotion, so the two
read as one family at a glance: same typeface (Playfair Display, Medium 500), same palette
(Espresso Earth `#3A2D28`, Rose Gold `#CBB1A5`, Porcelain Ivory `#FDFBF7`), same layout rules,
same full-stop device.

- `Logo/` — the wordmark, primary/reverse/monochrome, same as `Nurture Parenting Magazine
  rebrand/Brand Assets/Logo/` but set in "Nara."
- `Favicon/` — Solid Monogram favicon set (same treatment as Nurture's)
- `Social Profile/` — Ring Seal social avatar set (same treatment as Nurture's)

Each subfolder has its own `README.md` with the specific file list and usage notes (they mirror
the Nurture ones almost exactly — only the wordmark text changes).

## One thing worth knowing before you roll this out

Nurture and Nara both start with **N**, so the monogram used for the favicon and the social
profile "Ring Seal" is literally the same letterform on both — there's currently no visual way
to tell a Nara favicon/profile-picture apart from a Nurture one at a glance (the full "Nara."
wordmark is the only piece that's distinct). That's exactly what you asked for — same branding,
shared recognition — so I've kept it as-is. If down the track you'd rather the two be
distinguishable in browser tabs/profile pictures specifically (say, a different dot colour for
Nara, or a two-letter "Na" monogram), that's a small change to make — just say so.
