# Nara social profile picture — final set

Same "Ring Seal" treatment as Nurture's social avatar: Espresso Earth tile, hairline Porcelain
Ivory ring, centered "N", Rose Gold jewel dot — tested against a circular crop, since
Instagram/Facebook/LinkedIn/X all crop profile photos into a circle.

## Files

| File | Size | Use |
|---|---|---|
| `nara-social-profile-1024.png` | 1024×1024 | Upload this one everywhere |
| `nara-social-profile-512.png` | 512×512 | Smaller fallback, same image |
| `nara-social-profile-320.png` | 320×320 | Minimum-size fallback |
| `nara-social-profile-master.svg` | vector | Source file |

## Where to use it

Upload the **1024px PNG** as the profile photo on Nara's own Instagram / Facebook / LinkedIn /
X / Pinterest / YouTube / TikTok accounts. One square image, re-used everywhere — every
platform scales it down on its own.

## A heads-up on cross-promotion

Because Nara and Nurture share this exact monogram ("N"), the two profile pictures currently
look identical. If Nara and Nurture will run separate social accounts that people follow side
by side, you may want a small differentiator later (e.g. swap the jewel dot to a second brand
colour, or add a one-word label beneath in Stories/highlight covers) — happy to make that
change if you want it; for now this matches your "same branding, shared recognition" brief
exactly.

## Recolouring / resizing yourself

Open `nara-social-profile-master.svg` in a text editor and edit the `fill="#..."` /
`stroke="#..."` hex values. Re-export a PNG at whatever size you need.
