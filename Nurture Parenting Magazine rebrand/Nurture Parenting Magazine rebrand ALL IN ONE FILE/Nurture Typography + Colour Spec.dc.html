02

The five typography sets

Typography → Global Typography → Headings / Subheadings / Lead / Body / Small

This is the panel in your screenshots. Five collapsed rows, each opening the same eight fields. Right now Headings and Subheadings are both 24px / 1.4 / .2px / AB uppercase — identical to each other and shouting. That's the whole problem.

The uppercase rule — the whole site, in one line

Uppercase is allowed in exactly three places: the Label set / H6, buttons, and footer widget headings. Every other Text Transform field on this page is “–” (none). If you're unsure while clicking, pick “–”.

How this panel relates to section 04

These five are presets — Builder elements pick one from a dropdown (“use Headings”, “use Lead”). Section 04's H1–H6 fields are what plain page and post content renders as. Two separate panels, so you fill in both.

Keep them matched on purpose: Headings = H1 (46px), Subheadings = H3 (26px). The same numbers in both places is correct, not a duplicate.

These sets have no font colour field — colour lives only in Body Typography (03) and Heading Typography (04).
