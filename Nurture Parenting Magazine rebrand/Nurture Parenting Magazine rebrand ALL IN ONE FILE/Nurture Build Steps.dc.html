Nurture rebrand · build order

Do it in this order

Global settings first — every one of them changes the whole site at once, so fixing them before you touch a page means you don't rebuild anything twice. Then the Custom CSS clean-out. Then the homepage. Then pages, one at a time.

Back up first: Avada → Options → Import / Export → Export Options. Save that file. If anything goes sideways you can paste it straight back.

Phase one · about 30 minutes

Global Options

All of this is Avada → Options. Use the "Search for option(s)" box at the top — it's faster than hunting through the left panel. Hit Save Changes after each section.

What you're building towards: the homepage, Our Story, Advertise. Open one in another tab and keep it beside you — every value below is taken from those pages, so when you finish phase one your site's type and buttons will already match them.

0
Avada → Options → Typography → Google Fonts

Load the two typefaces first

Nothing else will look right until these are available. Google Fonts Load Method is already set to Local, which is correct — it keeps them fast and privacy-safe. In Preload Fonts Variants make sure 400, 500, 600 are ticked. Then, as you set each typography field below, choose Playfair Display or Inter from the font dropdown — Avada downloads and self-hosts them automatically the first time you save.

1
Typography → Typography Sets

Turn off the shouting

You have five sets: Headings, Subheadings, Lead, Body, Small. Set Text Transform to None on Lead, Body and Small. Leave Subheadings as uppercase. This one change is the biggest single improvement on the site — right now your paragraphs and captions are set in capitals, which is why it reads like a flyer.

2
Typography → Typography Sets

Settle on two typefaces

Headings → Playfair Display, 500. Subheadings, Lead, Body, Small → Inter (400 for body, 500 for subheadings). Delete Nunito and Montserrat wherever they appear. You're currently loading three sans families on every page load, which costs you speed for nothing.

3
Typography → H1 – H6

Fix the heading colours and the H2 font

H1 colour is currently Colour 3 — clay taupe at 35% opacity, so your headings are nearly invisible. Change to Colour 2 (Espresso Earth). H2 font family is currently Raleway Dots — a novelty dotted typeface, on every H2 on the site. Change to Playfair Display, 500, colour Colour 2. Set H3–H6 to Playfair Display, and turn Text Transform to None on all six.

4
Elements → Buttons

Make the buttons rose gold, properly

This is the green you've been fighting. Set:

Gradient Top Colour → #CBB1A5
Gradient Bottom Colour → #CBB1A5 (same value = flat, no gradient)
Accent (text) Colour → #3A2D28
Border Colour → transparent, Border Width → 0
Border Radius → 40px all corners
Hover: background #3A2D28, text #FDFBF7
Typography → Inter, 500, 13px, letter-spacing .09em, uppercase

5
Layout → Link Colours

Give links a hover state

Link colour and link hover colour are currently identical, so nothing happens on hover. Link → #8C6F61, hover → #3A2D28.

6
Menu → Main Menu

Bring the nav down to a nav size

Currently Playfair Display at 26px — a headline size for a menu item. Change to Inter, 500, 14px, letter-spacing .14em, uppercase. Colour Colour 2, hover Colour 4.

7
Background

Turn the background pattern off

Background Pattern → Off. Background Colour → Colour 1 (Porcelain Ivory), not Colour 3. Content Background → #FDFBF7, not pure white — pure white next to ivory reads as a mistake.

8
WooCommerce → Product Badges

Repair the sale badge

Sale Badge Text Colour is var(--awb-color1)fff — the trailing fff makes it invalid, so the text has no colour. Set it to Colour 1. While you're there: the "Sale!" badge text is doing you no favours on a premium magazine — change the text to the price or remove it.

9
Page Title Bar

Kill the 600px header block

Page Title Bar height is 600px with a parallax background image on every page — that's a full screen of decoration before any content. Set Page Title Bar → Hide globally, and build each page's own opening section instead. This is also what removes those repeated header curves.

Phase two · about 15 minutes

Clean out the Custom CSS

Once phase one is done, most of your Custom CSS is fighting settings that are now correct — and every !important you leave in place will block you from changing anything through the interface later.

10
Avada → Options → Custom CSS

Delete sections 1, 2 and 4

The global typography reset, the rose gold button override and the form field block are all now handled in Global Options. Delete them. Keep only the glass card and the soft border rule — replace the whole block with this:

/* Nurture — glass surfaces, soft borders, motion */

.nurture-glass{
  background: rgba(253,251,247,.72);
  backdrop-filter: blur(18px);
  -webkit-backdrop-filter: blur(18px);
  border: 1px solid rgba(215,203,194,.35);
  border-radius: 20px;
  padding: 40px;
  box-shadow: 0 10px 30px rgba(45,36,32,.05),
              inset 0 1px 0 rgba(255,255,255,.6);
  transition: transform .5s cubic-bezier(.2,.7,.2,1),
              box-shadow .5s;
}
.nurture-glass:hover{
  transform: translateY(-4px);
  box-shadow: 0 18px 44px rgba(45,36,32,.09);
}

/* soft borders instead of harsh dark ones */
.fusion-container,.fusion-column,
.fusion-layout-column,.fusion-builder-row{
  border-color: rgba(215,203,194,.35) !important;
}

/* image fading into the page — the section-divider replacement */
.nurture-fade{ position: relative; }
.nurture-fade::after{
  content: ""; position: absolute; inset: auto 0 0 0;
  height: 55%; pointer-events: none;
  background: linear-gradient(to bottom,
              rgba(253,251,247,0), #fdfbf7);
}

/* rose gold glow — one per screen, never more */
.nurture-glow{
  position: absolute; border-radius: 50%;
  pointer-events: none; filter: blur(4px);
  background: radial-gradient(circle,
              rgba(203,177,165,.42),
              rgba(203,177,165,0) 70%);
}

@media (prefers-reduced-motion: reduce){
  .nurture-glass{ transition: none; }
  .nurture-glass:hover{ transform: none; }
}
11
Avada Live Builder, every page

Remove the curved section separators

In each container's settings, find the Separator / Section Separator element and delete it. Those curved dividers between sections are the single most dated thing on the site — they're a 2016 look. Nothing replaces them: the image-to-ivory fade in step 12 does that job, and elsewhere generous whitespace and a single hairline is enough.

Phase three · the homepage

Rebuild the sections

Reference: the new homepage. Copy: the handbook, part two. Work top to bottom; publish as you go.

12

The image-to-gradient treatment

This is the pattern that replaces every curve on the site, and it's what makes it read as expensive. For each full-width photograph:

Container → 100% width, no padding. Add the CSS class nurture-fade in the container's Extra → CSS Class field. Background image set to Cover, height 520–620px. The ::after rule from step 10 fades the bottom half of the photo into the page background, so the image dissolves into ivory rather than stopping at a hard edge or a curve.

Put the section heading in that fade — bottom-aligned, centred, sitting on the ivory. Use it three times down the homepage: hero, blog, gift guides. Not more.

13

Section order

Hero (headline, one line, two buttons, then the fading photograph) → credentials strip → current issue with the three price cards → Print / Post / Planted → blog → mentors → gift guides → advertisers → Ask Nara and the newsletter, side by side → footer.

Deleted on purpose: the long "What's the buzz" introduction, the three pillars, and the stats counters. The pillar copy is rewritten in the handbook — use it on Our Story.

14

The rose gold rule

Rose gold is for buttons, focus rings, the full stop in the logo, and one soft glow per screen. It never becomes a background for a large block, and never a heading colour. The moment it's everywhere it stops reading as premium — that restraint is the whole difference between this and the current site.

15

The 3D cover shelf

Optional, and the one genuinely novel piece. Three covers overlapping, each rotated slightly further and pushed further back, parting on hover. It needs perspective: 1600px on the outer container and transform-style: preserve-3d on every wrapper between it and the covers, or the depth silently flattens. Working code is in direction 1c — your developer can lift it as-is into a Code Block element.
