Build sheet — one page at a time

Home — copy and what to use

Work down the page in order. Left column is the copy — select it and paste it in. Right column is the setting — the element, the heading level, the size. Nothing to look up anywhere else.

Where the right column says Label, that's the small uppercase line — Text Block, Inter 500, 12px, 2.4px letter spacing, colour #CBB1A5. It appears eleven times on this page, so set one up and duplicate it.
